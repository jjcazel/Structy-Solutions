## is palindrome

Write a function, _isPalindrome_, that takes in a string and returns a boolean indicating whether or
not the string is the same forwards and backwards.

#### test_00:

```js
isPalindrome("pop"); // -> true
```

#### test_01:

```js
isPalindrome("kayak"); // -> true
```

#### test_02:

```js
isPalindrome("pops"); // -> false
```

#### test_03:

```js
isPalindrome("boot"); // -> false
```

#### test_04:

```js
isPalindrome("rotator"); // -> true
```

#### test_05:

```js
isPalindrome("abcbca"); // -> false
```

#### test_06:

```js
isPalindrome(""); // -> true
```
